## 目标

R4-2 不新增后端聚合接口，先建立纯前端楼栋业务 ViewModel 与可复用展示组件。组件只接收 `props`，不得自行散落调用楼栋、巡检、人工智能、评分、证据或报告接口；R4-3 统一楼栋详情页负责一次性拉取并组装快照。

固定生命周期：

`ARCHIVE → INSPECTION → ANALYSIS → REVIEW → ASSESSMENT → DISPOSAL → REINSPECTION → REPORT`

统一状态：

`NOT_STARTED / PENDING / IN_PROGRESS / COMPLETED / ATTENTION / STALE`
